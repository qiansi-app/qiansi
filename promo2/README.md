# 宣传片（2026-11）

54 秒、1920×1080、30fps，全部画面来自**真实产品截图**，没有一张是示意稿。

## 结构

| 段落 | 内容 |
|---|---|
| 片头 0–5s | 牵丝 / QIANSI · 多 AI 协作画布，丝线动画 + 三条标签 |
| 01 画布 5–12.5s | 全幅：节点是模型，连线是分工 |
| 02 产物 12.5–20s | 卡片：每一级产物挂在连线上 |
| 03 运行 20–27.5s | 推近进度条：逐任务验收、耗时与花费 |
| 04 KEY 27.5–35s | 全幅：一枚 Key 一个家族、额度与轮换 |
| 05 接续 35–42.5s | 卡片：接续任意 agent 会话 |
| 06 对话风格 42.5–49.5s | 卡片：每种场景一种说法 |
| 片尾 49.5–54s | 把重活，画出来再跑 + 安装命令 |

## 生产流程

1. `shots/`：从运行中的牵丝（`127.0.0.1:<port>`）用 Electron 无头截取 1920×1080 的真实界面。
2. `promo.html`：场景 + 时间轴，`window.seek(ms)` 是唯一的时间入口，逐帧确定性。
3. 渲染：Electron 按 1/30 秒步进 seek → 双 rAF 强制重绘 → `capturePage()` → JPEG 管道送给 ffmpeg（`libx264 -crf 18`），中间帧不落盘。

## 复现

```bash
# 1. 产品截图（需要牵丝在跑）
electron promo2/scripts/shots.cjs
# 2. 关键帧预览（先看排版）
electron promo2/scripts/preview.cjs
# 3. 全片渲染
FFMPEG=… electron promo2/scripts/render.cjs
```

脚本里写死了本机 ffmpeg 路径与本机端口，换机器时改两行常量即可。

关键三点（踩过的坑）：

- **离屏渲染必须双 rAF 同步再截图**，否则拿到的是上一帧，整片会错位。
- 非 16:9 的截图不要全幅 `cover` 放大（1500→1920 会发虚），用「浮起卡片 + 近原生尺寸」。
- 字幕放在底部渐变压暗带上；章节小标放字幕上方，避开产品截图自己的工具栏。
