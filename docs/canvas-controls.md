# 画布操作

## 一键工作流

顶栏的星标图标打开「一键生成工作流」：

1. 填写任务目标；
2. 选择主控模型和工作模型；
3. 可附加文件或整个文件夹（会上传到公共文件库）；
4. 点「生成工作流」。

主控模型会返回 3–5 个节点的分工和连线（任务 / 交付 / 验收），生成后会替换当前画布并自动排版。模型连接、设置和已有文件不会删除。

## 主控模型

- 点击任意模型节点 → 「能力」页 → **设为主控模型**。
- 原主控会自动降为普通节点；画布上的皇冠标记、运行派发和评委名册都会跟着切换。
- 主控节点不能删除；先切换主控再删。

## 自动排版

顶栏 **排版** 会先立即按本地分层算法排好，再把节点与连线交给主控模型优化坐标；模型不可用时保留本地结果，主控最多等待 25 秒。布局横向展开：主链按依赖从左到右排列，没有连线的模块放在底部一排；排版完成后自动缩放视图，保证整张图都在可视区内。

规则：主控在最左列，按依赖从左到右分层，同层纵向排列。区域内的节点不参与全局排版，跟随区域移动。

## AI 讨论

1. 按住 **Ctrl / ⌘**（或 Shift）点选 2 个以上模型节点；
2. 顶栏 **讨论 N**；
3. 输入主题，选择 1–3 轮，开始。

每个模型依次发言，后发言者能看到前面所有观点。讨论结果可以「存为产物模块」，以独立产物节点留在画布上。

## 任务与产物模块

- 运行结束后，在「结果」面板每条任务右侧点 **任务** 或 **产物**，即可把它们拉到画布。
- 每个子任务一完成，产物卡片就出现在它来源节点的连线上（不必等整轮结束）；连线上的卡片可点击查看该级产物与验收。
- 已拉到画布的产物模块，检查器里有 **放回流程线**：节点收起，产物回到来源节点的连线，重启后仍在。
- 点击任务/产物模块打开右侧检查器：查看内容、隐藏、删除。
- 检查器里的 **复制模块** 会生成一份独立副本（名称带「副本」），副本与主流程互不影响，适合放进分项目里改而不动原件。
- 设置 → 外观 → **画布显示任务模块** / **流程线上显示产物** 可以整体开关；单独隐藏用检查器里的「隐藏此模块」。

## 文件模块

顶栏 **文件** 上传（单文件上限 8 MB），生成一个文件节点：

- 文本类文件会显示前 1200 字预览；
- 从文件节点右侧端口可以拖出**多条**连线，同时连到一个或多个模型、任务节点；
- 文件保存在 `~/.qiansi/files/`；删除文件模块时会同时删除磁盘上的文件。

## 文件库

文件库是一个可以装多个文件的节点，适合把一批资料统一供给多个节点。

- 顶栏 **文件库** 创建一个私有文件库；右侧检查器可以**多选文件**或**整个文件夹**上传，目录里的相对路径会保留（例如 `qiansi-folder/sub/b.txt`）。
- 私有文件库用连线手动接到一个或多个节点。
- 把文件库设为 **公共文件库** 后，它会自动连到所有模型节点（虚线 `公共文件`），新增模型节点也会自动连上。
- 公共文件库的内容会作为上下文注入节点聊天和多模型讨论；私有文件库只影响与它相连的节点。
- 新画布会自动生成一个「公共文件库」；从旧画布恢复时如果没有公共库也会自动补一个。

## 分项目区域（画笔）

1. 顶栏 **画笔**，在旁边选择方向：双向 / 单向入 / 单向出 / 封闭；
2. 在画布上拖拽出矩形；
3. 落点范围内的节点会自动归入区域，区域标题栏可拖动整体移动。
4. 之后把任意节点（模型、任务、产物、文件、文件库）拖进区域会提示「已纳入」，拖出边界会提示「已移出」；归属按节点中心点判断，区域可整体移动子节点。

方向决定跨边界连线：

| 模式 | 主工作流派活进区域 | 区域交付到主工作流 |
|---|---|---|
| 双向 | 允许 | 允许 |
| 单向入 | 允许 | 阻止 |
| 单向出 | 阻止 | 允许 |
| 封闭 | 阻止 | 阻止 |

被阻止的连线会弹提示，不会创建。区域内部连线不受限制。

区域可点击后在右侧检查器切换方向、隐藏或删除；选中区域后拖动四角或四边的手柄即可调整大小，新尺寸会随画布保存。删除区域不会删除区域内的节点，它们会连同绝对坐标一起移出。

## 画布持久化

节点位置、连线、区域、任务/产物/文件/文件库模块、隐藏状态和主控选择会自动保存到 `~/.qiansi/canvas.json`（停止拖动约 0.8 秒后写入）。重启应用会恢复上次的画布；运行结束时临时生成的最终产物节点不落盘，上传的文件仍保存在 `~/.qiansi/files/`。

## 清空画板

「更多 → 系统 → 清空画板」会在确认后移除所有节点、连线、运行状态和对话记录。模型连接、设置和已经上传的文件保留；空白画布会被保存，重启后仍是空的。

## 删除

所有可删除的节点在悬停时显示垃圾桶按钮，点击后弹出统一的确认框。为避免误删，画布不再响应 Delete/Backspace 键；区域删除会保留子节点，任务/产物删除只影响该模块。
