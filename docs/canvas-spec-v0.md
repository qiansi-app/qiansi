# 画布规格 v0

> 已被 [canvas-spec.md](canvas-spec.md)（v1.0，来自画布深挖工作流）取代。本文件保留为实现基线：当前 Studio 的节点/连线/对话抽屉就是按它做的。

## 1. 节点解剖

```
┌───────────────────────────────────────────┐
│ ● 资料员            [high]   ⋮            │  状态点 + 名称 + effort 徽章 + 菜单
│ DeepSeek · deepseek-reasoner              │  模型行
│ ─────────────────────────────────────────  │
│ 正在核对第 3 条来源…                       │  单行进度回声（不放大段流）
│ ○ in    assign →              review ○    │  类型化端口
└───────────────────────────────────────────┘
```

- orchestrator：琥珀色描边 + 皇冠；全图唯一，保存时校验。
- provider 左侧 3px 强调色（DeepSeek 蓝、MiniMax 橙、Claude 陶土、Kimi 紫、Qwen 绿）。
- 节点默认紧凑；悬停显示快捷操作（聊天、重跑、改派、复制）。
- 成本微型条：节点底部一条 2px 细线，按本节点本次运行 token 占比着色。
- 状态点：灰 idle、蓝 queued、青 running、紫 reviewing、绿 done、红 failed、黄 blocked-on-user。

## 2. 端口与连线

| 类型 | 含义 | 方向 | 颜色 |
|---|---|---|---|
| `assign` | 派发子任务 | 上游 → 下游 | #6ea8fe |
| `handoff` | 产出物作为输入 | 上游 → 下游 | #38d9c9 |
| `review` | 验收/审查 | 下游 → 上游 | #e0a458 |
| `context` | 共享上下文，不触发执行 | 双向虚线 | #5f6b7a |

- 连线承载策略：`policy { allowedTaskKinds[], maxParallel }`，调度器在分派前读取。
- 从端口拖出；松开在空白处弹出节点搜索（easy-connect）。
- 边中点可加标签；支持 reroute 节点；点击边打开共享线程 + 事件流。
- 连线动画只在有数据传输时开启，避免全图常亮。

## 3. 节点状态机

```
idle → queued → running → reviewing → done
                  ↑          │
                  └ revising ┘（attempts < 2，effort 升档）
reviewing → failed（重试耗尽）→ blocked-on-user（选择卡）
blocked-on-user → queued（用户选择重试/改派）| failed（用户终止）
```

每种状态的视觉：状态点颜色 + 节点底部单行文本（排队中 / 生成中 / 验收中 / 已返修 1 次 / 等待你决定）。

## 4. 画布级交互

- 节点面板：搜索 + 按 provider 分组 + 拖拽入画布。
- 多选成组（subflow）可折叠；便签（sticky note）只做人类批注，不参与执行。
- 小地图、缩放控制、点阵背景；缩放 < 60% 时节点退化为「图标 + 名称 + 状态点」。
- 撤销/重做必须在 v0.1（zundo 或自建命令栈）。
- 自动保存到本地；图快照与运行快照分开存储。
- 运行条：Run/Pause/Stop、当前波次、token/费用、并发数。
- 命令面板（Ctrl/Cmd+K）：加节点、搜索节点、运行、打开运行历史。

## 5. 点击即对话

- 点击节点：右侧抽屉（可拖宽、可固定），标签页 Chat / Tasks / Logs / Profile。
- Chat 是与该槽位的持久线程；每条消息带所属 subtask 徽章；聊天消息可“提升为返修备注”。
- 流式输出只进抽屉；节点内只显示一行进度回声。
- 底部覆盖操作：改 effort、改派任务、重跑、跳过、编辑验收标准后重跑。
- 拖拽任务卡片到另一个节点 = 改派：中止在飞请求，发出 `TaskReassigned`，在新节点重开 attempts，记录 `human_override`。
- Profile 标签页：显示并编辑能力档案（协议、模型、effort 方言、上下文、成本、强项、健康度）。

## 6. 选择卡

- 只在四类真实取舍出现：成本/质量平局、预算 80%、验收低置信、重试耗尽；另加“所有模型冷却中”。
- 每张卡 2–4 个选项，每个选项带 `costDelta` 与 `qualityHint`；选择写入偏好权重。
- 卡片固定在右下角或对应节点旁；选择后折叠进运行历史。

## 7. 快捷键（v1）

| 键 | 动作 |
|---|---|
| Space + 拖拽 | 平移画布 |
| Ctrl/Cmd + K | 命令面板 |
| Ctrl/Cmd + Z / Shift+Z | 撤销 / 重做 |
| Delete | 删除选中节点/边 |
| Enter | 打开选中节点聊天 |
| R | 运行选中节点/整图 |
| Esc | 关闭抽屉/取消连线 |

## 8. 视觉方向

深色、扁平有层次：近黑背景（#0B0D10）、1px 边框、轻微 elevation；只在浮动面板/命令面板/对话框使用模糊。参考 Sim 的信息密度、Langflow 的节点手感、LobeChat 的设置面板。禁止在数百节点上使用 backdrop-filter。
