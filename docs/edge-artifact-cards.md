# 连线上的次级产物卡片

2026-11-08。用户报了两个问题：连线上的产物**没有美术**（纯文字小方块），**且压在连线上**。修复方案由画布自己跑出来（交互设计师 / 布局工程师 / 评审员三个节点），本文件是落地结果与验收数据。

## 设计（来自画布产物，经实现校正）

**卡片结构**：状态图标 + 类型（任务/交接/验收/上下文）+ 任务 ID + 状态徽标（通过/需人工/未通过）+ 标题 + 两行摘要 + 右下角评分；左侧 3px 状态条。状态用**颜色 + 图标 + 文字**三重表达，不只靠颜色。

**不压线**：卡片从连线中点沿**法线**偏移，偏移量取 `max(基础间距, 卡片在该方向的半尺寸 + 14)`；短线（<220px）基础间距更大。

**不压节点**：卡片在候选位里挑第一个不与任何节点矩形相交的——两侧各试 3 个距离，再沿切线前后各滑 2 档（共 14 个候选），全撞则退回首选项。

**缩放一致性**（评审员提出的关键点）：`EdgeLabelRenderer` 随画布缩放，所有几何一律用画布单位，禁止混入屏幕像素；卡片刻意随画布缩放，不做 `scale(1/zoom)`。

**连接关系**：卡片与连线之间画一条虚线引导线 + 锚点圆点，颜色跟随状态。

## 实测数据（Electron 无头 + DOM 断言）

| 断言 | 修复前 | 修复后 |
|---|---|---|
| 卡片数量 / 锚点数 | 3 / 3 | 3 / 3 |
| 卡片盖住锚点 | `[true, true, true]` | `[false, false, false]` |
| 与节点重叠数 | 未测（肉眼可见重叠） | `[0, 0, 0]` |
| 卡片尺寸 | 211×82 | 211×82（固定） |

第一次实现偏移 40px，小于卡片半高 41px——测出仍压线 1px，据此改为按法线方向取半尺寸。第二次测出不压线但压节点，补了候选位搜索。

## 顺带修掉的运行缺陷

这次画布运行的「汇总员」（GLM-5.3-flash）**空产出失败**：21,205 条推理流、正文 0 字，超时与重试都救不回来。根因是智谱模型**始终思考、拒绝 `thinking:disabled`（错误码 1210）**，所以「空产出时降 effort」对它完全无效。

修复：空产出重试时，在系统提示词里追加一条明确指令——「上一次尝试没有产出正文（推理耗尽预算）。这一轮直接给答案，不做分析」。单元测试用假适配器验证：第一轮无此指令，第二轮有。
