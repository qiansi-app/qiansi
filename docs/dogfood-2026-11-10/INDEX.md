背景：牵丝是本地多 AI 编排画布（Electron + React + 纯 TS 引擎 + 本地 Hono 服务），仓库就是它自己。用户希望加一个能力：项目自己复盘、自己运行检查、自己发现自身问题，再上网找竞品与论文，然后优化自己。用户只设置「模式」和「程度」，界面要预测 token 消耗，用户可以设用量上限让它持续迭代，每个版本要留存、可随时切换回来。
