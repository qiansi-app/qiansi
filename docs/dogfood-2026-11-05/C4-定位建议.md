## 定位陈述（可公开使用）

牵丝是面向单人开发者的本地优先 Agent 任务画布。它以主控—Worker 分解任务，把 Claude Code、Codex 等外部编码 Agent 当作一等公民：上游产出自动注入下游提示词，逐任务验收（结构检查→便宜闸门→完整评委）并回写产物，形成可审计、可回滚的本地执行链。Key 按模型家族统一管理并本地加密，运行数据不出域；桌面版、VS Code 扩展与 Web Studio 三形态零部署、零运维。牵丝刻意不做云托管、多人协作、SaaS 集成、RAG、定时触发和 worker 联网。

注：该陈述未引用资料包中未核实的精确数字与争议叙事。

## 三条真实优势

1. **任务级验收与回写闭环**：竞品画布多为数据流或功能步骤流，无验收/评委概念；牵丝把结构检查、便宜闸门、完整评委和产物回写内建到执行循环。
2. **Key 与治理成体系**：一枚 Key 服务一个模型家族、模型目录路由、CC Switch 导入、DPAPI 本地加密；相比竞品的逐供应商凭据、服务器库存储或云托管 Key，更适配本地单人场景。
3. **本地三形态 + coding agent 一等公民**：Electron 桌面、VS Code 内嵌服务端、Web Studio 零部署；MCP、插件与 /v1 网关把 Claude Code/Codex 作为编排对象，而非仅是工具接入。

## 三条最刺手劣势

1. **无子工作流复用与嵌套**：ComfyUI、Flowise、Langflow、n8n 均支持子图复用或嵌套，牵丝画布间不可复用，复杂流程重复编排成本高。
2. **无节点级运行追踪与跨版本回归**：Sim、Flowise、frameworks 提供块级追踪、数据集评估或轨迹回放；牵丝仅有会话级用量统计，失败定位和回归对比弱。
3. **缺少 HITL 暂停/断点审批**：Flowise、Langflow 支持检查点，牵丝目前验收失败即结束，运行中不能暂停等人裁决后继续，高风险流程需整段重跑。

## Top3 行动建议（按优先级排序）

1. **节点级运行追踪 + 版本快照/diff**  
   在现有会话用量统计上下钻到节点，并保存本地运行快照，支持同一画布两次运行的差异对比。  
   - 验收标准：任一节点运行后可在画布查看输入、输出、耗时、Token/费用、失败原因及验收中间结果；同一画布至少两次运行可生成结构/结果/成本 diff；快照可转模板，全部本地存储、断网可用。

2. **子工作流复用与嵌套**  
   支持从选中节点组保存本地模板，模板可实例化、绑定参数，至少一层嵌套，导出/导入 JSON；不做在线市场。  
   - 验收标准：节点组可保存为模板并在其他画布实例化；模板支持至少一层嵌套且不丢失上游注入与验收语义；模板可 JSON 导入/导出，格式有文档。

3. **HITL 暂停审批/断点续跑**  
   在工具执行前、费用闸门前、产物提交前增加检查点，运行到达后本地持久化，用户放行后从断点继续；首版仅桌面有人值守场景。  
   - 验收标准：用户可在指定节点前配置检查点，运行到点暂停等待放行/中止；暂停状态本地落盘，应用重启后可继续或中止；人工放行记录进入审计日志。
