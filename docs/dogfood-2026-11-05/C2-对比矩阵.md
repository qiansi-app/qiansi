# 牵丝 × 8 竞品 功能对照矩阵（基线：资料包「牵丝现状」2026-11-05）

**级别定义**
- **【核心】** 与「本地优先 / 单人开发 / 无运维」约束兼容，且直接影响目标用户日常编排闭环 → 应补。
- **【边缘】** 有价值但非闭环必需，或可用最小替代挡住。
- **【刻意不做】** 资料包「牵丝现状」明列的 6 条不做项（云服务、多人协作、SaaS 集成、RAG、定时触发、worker 联网）；**括注（推断）**者为依产品定位判定、非资料包明列。

## 矩阵汇总（供机会分析员与定位建议员直接取用）

### A. 跨竞品反复出现的【核心】差距 → 建议进 Top3 候选池
| # | 差距 | 共现竞品 | 关键理由（约束兼容性） |
|---|---|---|---|
| 1 | **子工作流复用 / 画布嵌套** | comfyui、flowise、langflow、n8n | 纯本地能力，无运维成本；可优先兼容 ComfyUI subgraph JSON 降低迁移成本 |
| 2 | **HITL 断点续跑 + 人工放行** | flowise、langflow | 是牵丝「逐任务验收」的天然延伸，不是新赛道 |
| 3 | **画布版本快照 + 运行前 diff** | dify、langflow、sim、n8n | 本地 SQLite/文件快照即可，不碰云；顺带承接「运行历史→可复用资产」 |
| 4 | **节点级运行追踪 / 轨迹回放** | sim、frameworks、flowise | 已有会话用量统计，下钻成本低，直接补开发者信任面 |
| 5 | **可保存数据集 + 跨版本回归评估** | flowise | 把验收从「单次运行」升级为「可回归」，差异化最强 |
| 6 | **协议面：ACP 通道 + A2A/agent card** | coze、frameworks、langflow、n8n | 本地子进程/本地端点，不破无运维；与「coding agent 一等公民」同向 |
| 7 | **「会话/agent 即端点」+ per-agent 可撤销令牌** | n8n（待核）、langflow | 复用已有只读令牌，最小成本对齐「agent 即产物」 |
| 8 | **节点级试跑调试** | coze | 单 worker 单独试跑，低成本 |
| 9 | **编译型规则守卫（policy→guard→人工审→启用）** | langflow | 治理是牵丝护城河，属同向升级而非跟随 |

### B. 【边缘】差距（建议明确排期靠后或做最小版）
内置长期 memory（frameworks）· 自然语言→画布草案（n8n/langflow/coze，仅最小版）· 代码执行沙箱（dify，需安全评估）· 插件机制（dify）· 桌面自动更新（langflow）· 41 工具面扩宽（comfyui）· 轻量表格/文件节点（sim）· Chat 建 agent（sim）· 浏览器扩展（sim）

### C. 【刻意不做】清单（对外文案应主动声明，而非回避）
云托管 / 云 GPU / Credits（comfyui、dify、sim、n8n）· 多人协作 / CRDT 共编 / 工作区 / 企业 SSO·SCIM·权限组（comfyui、coze、dify、flowise、sim）· SaaS 集成与触发器体系（n8n、sim、langflow、flowise）· RAG 向量库（dify、langflow、sim）· 发布成 webapp / 飞书微信 / 插件市场 / 模板库规模（coze、dify、n8n、sim）· 托管模型免 Key（n8n）· 多语言 SDK / 海量模型目录（frameworks）· K8s 部署（sim）· 媒体生成（comfyui、sim，**推断项**）

### D. 牵丝独有、8 家均无对等物（定位陈述的一级弹药）
1. **任务级编排语义**：worker 子任务 + 上游产出注入下游提示词 + 逐任务验收（结构检查→便宜闸门→完整评委）+ 产物回写节点。全部 8 家的「图」都是数据流或功能步骤流，无验收/评委概念。
2. **Key 治理成体系**：一枚 Key 服务一个模型家族 + 模型目录路由 + CC Switch 导入 + DPAPI 加密保险库（对比：Flowise 存服务器库、Langflow 全局 provider 面板、n8n 逐节点建凭据、Sim 云端托管）。
3. **本地治理三件套 + 三形态**：作用域+acceptMode、只读令牌、审批中继；Electron 桌面 + VS Code 内嵌服务端 + Web Studio，零部署零运维、数据不出域。
4. **Windows 桌面 + 国内模型家族深度**（Sim 桌面仅 macOS，后四家覆盖未查到）。
