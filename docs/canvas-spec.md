# AI 团队画布 · 交互与功能规格 v1.0

> 一句话定位：画布不是一次性工作流，而是一支常驻 AI 团队的「组织图 + 工作台」。节点是成员，连线是长期协作契约，任务是在契约上流动的实例。

**术语**
- 节点（Node）：一个已接入的模型成员。
- 契约边（Contract Edge）：长期连线，声明「谁可以把哪类信息交给谁」。
- 任务（Task）：一次运行中的委派实例，编号 T1…Tn。
- 运行（Run）：一份图快照的一次执行，有独立 runId。
- 主模型（Main）：唯一被指定为编排者的节点。
- 尝试（Attempt）：同一任务的一次执行；返修、重跑递增。
- 冻结（Pin）：把某次产物固定为下游输入基线，后续重算跳过。

**设计公理**
1. 图讲团队，运行叠加实例：结构边稳定，任务与产物沿边流动并留下徽章，不因一次运行重画拓扑（区别于 ComfyUI/Dify 的「图即程序」）。
2. AI 的所有动作必须在画布上可见：计划、传递、返修、验收都有就地痕迹，聊天不是唯一记录（Miro / FigJam「AI 在画布上动手」）。
3. 单击是选中，双击或 Enter 才打开；重操作不弹模态（n8n）。
4. 人工优先于编排器，但必须留痕、把下游标脏、绝不悄悄重复烧 token（n8n dirty + pin 思想）。
5. 所有状态不只靠颜色：图标 + 文本 + 形状三重编码（无障碍，色盲安全）。

## 1. 节点解剖

### 1.1 尺寸与栅格
- 默认宽 264px；可用 NodeResizer 在 240–320px 间调整（只影响换行，不改变布局结构）。展开高 176px，折叠高 40px，紧凑态 76px。
- 圆角 12px，边框 1.5px，阴影 `0 1px 2px rgba(0,0,0,.08)`，悬停 `0 4px 12px rgba(0,0,0,.14)`。
- 卡片背景为实色（非毛玻璃），保证从其下方经过的连线仍可读；内部横向内边距 12px，行间距 6px。
- 端口不占行高，挂在左右边缘固定纵向锚点（见 1.5）。

### 1.2 结构分区

```
┌────────────────────────────────────────────────┐
│ [厂商标] Worker 3 · DeepSeek   [冠] T4 ●   ⋯  │ 32px 头部
├────────────────────────────────────────────────┤
│ ● 运行中   deepseek-chat   ▂▄▆ 高(编排)  2/3   │ 22px 状态行
│ 正在核对第 3 节引用与数据口径……                │ 任务行 1–2 行
│ ┌────────────────────────────────────────────┐ │
│ │ …差额来自渠道返点，需在结论中单列…          │ │ 44px 产物预览
│ │ ▌                                          │ │ 流式尾行 + 渐隐
│ └────────────────────────────────────────────┘ │
│ 4.2k tok · ¥0.03 · 12s                [停止]   │ 20px 指标行
└────────────────────────────────────────────────┘
   ○任务口  ○产物口  ○语境口        产物口○  验收口○(仅主模型)
```

### 1.3 头部
- 左：厂商圆标 16px（DeepSeek / MiniMax / Claude / OpenAI / 自定义）、名称 13px/500 单行省略；悬停显示全名 + modelId + 凭证别名。
- 右：主模型皇冠（仅主模型，金色线性皇冠 14px，悬停「主模型」）、任务号徽章（`T4`，10px 等宽，悬停显示任务标题）、状态点、`⋯` 菜单（对话 / 运行本节点 / 设为主模型 / 固定 / 复制 / 禁用 / 删除）。
- 头部整块是折叠点击区；折叠后仅保留厂商标、名称、皇冠、任务号、状态点。
- 双击头部 = 打开对话抽屉（整卡双击同）。

### 1.4 状态行、任务行、产物预览、指标行
- 状态行：状态 chip（图标 + 文字，12px）、模型短名（等宽 11px 浅底）、档位三格柱 `▂▄▆` + 低/中/高、返修计数 `2/3`。档位来源用前缀区分「编排 / 人工 / 默认」；人工覆盖加手形图标和类型色描边。返修达到上限时计数变红并显示「需人工」。
- 任务行：当前任务一句话，最多 2 行（12px 次级色）。未分配时显示「待命 · 双击对话」；排队多个任务时显示「下一个：T5」。
- 产物预览：最近一次产物尾部 2–3 行，底部 12px 渐隐 mask；流式时实时滚动。右上角「3 份」chip 表示产物数量；已验收产物带 ✓ 角标。点击预览 = 打开抽屉「产物」tab。
- 指标行：tokens / 成本 / 耗时；右侧悬停出现「停止」（运行中）或「重跑」（完成/失败）。无数据时显示 `—`。

### 1.5 端口位置与样式
- 圆点直径 9px、2px 白描边；命中区 24×24；悬停放大至 12px 并浮出类型名（ComfyUI）。
- 左侧输入（自上而下）：任务口 y=32%、产物口 y=52%、语境口 y=72%；右侧输出：产物口 y=40%，主模型额外有任务口 y=24%、验收口 y=64%。
- 可选输入（语境口）常态空心，已连接实心（ComfyUI 空心可选输入）。
- 未连接端口在节点悬停时提亮；拖线时只点亮兼容端口，其余降到 30%。
- 端口不常驻文字标签，避免节点膨胀；仅在拖线和悬停时显示标签。

### 1.6 选中浮动工具条与右键菜单
- 单选时在节点上方 8px 浮出工具条（React Flow `NodeToolbar`）：对话 / 运行 / 改派…（高亮任务托盘）/ 设为主模型 / 固定 / `⋯`。
- 多选时工具条变为批量操作：运行选中 / 分组 / 对齐 / 删除。
- 右键菜单：对话、运行本节点、仅运行到此处、固定/冻结、禁用、复制、删除、查看日志、复制 JSON。
- 节点右键空白（画布）菜单：添加节点、粘贴、新建便签、新建分组、适应画布、导出 JSON。

### 1.7 尺寸态
- **展开**（默认）：全部分区。
- **紧凑**（缩放 < 0.6 自动）：只保留头部 + 状态行；隐藏产物预览与指标行。
- **折叠**（Alt+C 或头部按钮）：40px，保留端口可用性。
- 主模型自动带出下方任务托盘与计划条（它们是 `parentId` 子节点，随主节点拖动）。
- 组内节点同宽；组折叠时全部子节点隐藏。

### 1.8 视觉 token（集中管理）
- 状态色：运行蓝 `#3B82F6`、成功绿 `#22C55E`、验收绿 `#16A34A`、失败红 `#EF4444`、返修琥珀 `#F59E0B`、阻塞紫 `#8B5CF6`、空闲灰 `#94A3B8`、禁用中性 50%。
- 类型色：任务靛蓝 `#6366F1`、产物翠绿 `#10B981`、验收琥珀 `#F59E0B`、语境紫罗兰 `#8B5CF6`。
- 字体：系统 UI 字体 + 等宽（数值）；暗色主题只替换 token，不写死颜色。

## 2. 端口与连线语义

### 2.1 线是什么：契约，不是这一次的任务
- 一条线 = 一份长期授权：源节点在运行时可以把某类型的信息交给目标节点。它回答「谁可以找谁、交什么」。
- 一次任务分配、一次产物传递 = 沿既有契约边流动的**实例**，用边上的徽章、动画和日志表达，不新建拓扑。
- 同一对节点可以有多条不同类型的边（通常是一条任务契约 + 一条产物契约；主模型到工人还可能有验收/返修边）。同类重复连线自动合并并提示；平行边在路径上左右偏移 ±10px，各自带中点标签。
- 编排器想委派给没有契约的节点时，创建「临时委派边」：虚线、60% 不透明度、琥珀「临时」小标签；运行结束自动消失，用户可点「固化」转为正式契约（默认询问一次，可设不再问）。[决策] 临时委派边默认保留还是自动消失。
- 好处：画布长期稳定可读，运行轨迹不会把画布搅成蜘蛛网（针对 ComfyUI 30+ 节点线缠绕问题）。

### 2.2 端口类型与颜色

| 类型 | 端口 | 颜色 | 语义 | 谁发出 |
|---|---|---|---|---|
| 任务 Task | 输出（主模型）/ 输入（所有） | 靛蓝 #6366F1 | 任务书：目标、约束、交付物、验收标准、预算、档位 | 主模型 |
| 产物 Artifact | 输出 / 输入 | 翠绿 #10B981 | 结构化交付物（Markdown / JSON / 文件引用） | 所有节点 |
| 验收 Verdict | 输出（仅主模型），经目标节点的「任务口」进入 | 琥珀 #F59E0B | 通过 / 返修 / 改派 / 升级人工 + 理由 | 主模型 |
| 语境 Context | 输入（可选） | 紫罗兰 #8B5CF6 | 背景资料、便签、知识、上游产物摘要 | 便签或任意产物口 |

颜色在端口、线、标签图标三处一致（ComfyUI typed links / Langflow typed ports）。不允许只靠颜色：端口悬停显示类型名，线中点标签带类型图标（剪贴板 / 方块 / 天平 / 回形针线性图标）。

### 2.3 连接合法性

| 从 \ 到 | 任务口 | 产物口 | 语境口 |
|---|---|---|---|
| 产物口 | 禁止 | 允许 | 允许 |
| 任务口（主） | 禁止 | 禁止 | 禁止 |
| 验收口（主） | 允许（仅返修） | 禁止 | 禁止 |
| 便签 / 文档对象 | 禁止 | 禁止 | 允许 |

- 产物边必须无环：`isValidConnection` 实时判定，会成环则禁止并提示（React Flow v12 在拖拽全程持续评估）。
- 唯一反向边是「返修」：主模型验收口 → 工人任务口；由 attempt 预算封顶（默认 3），运行时不无限循环（Flowise Loop「Max Loop Count」语义）。
- MVP 禁止主模型→主模型、工人→任务口；V2 再开放工人向下委派子任务（[决策] 是否需要层级委派）。
- 从输出口拖出时只点亮合法输入；释放到空白弹出「可连接节点搜索」，按类型过滤（ComfyUI Link Release）。拖到已有节点任意位置也视为连到其兼容端口（`connectionRadius` 放大命中）。

### 2.4 线的绘制规则
- 默认贝塞尔曲线；设置可切直角 / 直线（全局或单线）。线宽 2px，按 zoom 反向缩放（n8n `--canvas-zoom-compensation-factor`），任何缩放下保持可读。
- 终点一律 `ArrowClosed` 箭头，指向消费者。
- 中点标签（`EdgeLabelRenderer`）：类型图标 + 摘要。静态态显示契约：`任务 · T4 · 第 2 次` / `产物 · 1 份 · 4.2k tok · 12s`；在途显示「传输中」；错误显示 `× 3`。
- 线绘制在节点之下，保持节点可读；但被选中的线提升到节点之上高亮（避免 ComfyUI 线被节点压住的问题）。
- 悬停加粗至 3px，中点浮出三个小按钮：详情（开抽屉）/ 加注 / 断开（React Flow v12 `EdgeToolbar` 思路）；从输入口拖离可摘下连线（ComfyUI detach）。
- 标签随缩放补偿，字体最小 10px；缩放 < 0.6 时只保留类型色与箭头，隐藏文字。

### 2.5 线的交互
- **点击**：打开右侧抽屉「连线模式」（见 5.3）。
- **拖到空白**：类型过滤的节点搜索，选中即建节点并自动连好（ComfyUI / Langflow 端口开新节点）。
- **改接端点**：拖动已有边的目标端到另一节点 = 改派该契约（`reconnectEdge`），弹档位确认，写审计（tldraw workflow kit 的「drag an existing connection to reconnect it」）。
- **中转点**（V2）：Alt+点击线插入 8px 小圆点，存入边的 `reroutes` 元数据而非建节点，保住类型校验与 JSON 导出整洁（ComfyUI RFC 0002）；双击删除，拖动改走向。
- **批量**（V2）：Shift+拖多线、Ctrl+Alt+点击清空某端口全部连线（ComfyUI）。
- **设置**：隐藏全部线（只留选中节点相关）/ 仅显示运行中的线（V2）。
- **断开**：悬停 X、选中 Delete、或从端口拖离。

### 2.6 线的状态（优先级从高到低，仿 n8n）
1. **阻塞/待放行**：紫色，停在中点，手掌徽章脉动；点击开批准卡。
2. **错误/重试**：红色描边 + 中点 `×N`；悬停显示最近错误原因。
3. **在途**：虚线行进动画 + 一枚流动光点，标签「传输中」。
4. **脏（stale）**：琥珀虚线，说明「上游产物已过期」（n8n dirty）。
5. **成功**：正常类型色 + 数据标签；空闲 10 分钟后回到类型色无标签。
6. **空闲**：类型色实线。

### 2.7 按住 / 放行（把 HITL 闸门放在线上）
- 线设置里开「交接需人工放行」（Flowise Human Input 语义搬到边上）。
- 触发时线在 50% 处停住，就地弹出「待放行」卡（非模态）：载荷预览 / 可编辑草稿 / 三个按钮——通过、改后通过、打回（填原因并回到上游任务）。按钮语义直接映射为出边行为。
- 决策后线继续流动，并写入审计；超时策略 [决策]（默认不自动放行，进入「需要你」收件箱）。

### 2.8 边的数据结构
`ContractEdge { id, source, sourcePort, target, targetPort, type, label, hold, reroutes[], meta }`。运行实例（在途、次数、token）只写入运行快照，不回写画布 JSON。

## 3. 节点状态机

### 3.1 九个状态

| 状态 | 含义 | 谁触发 |
|---|---|---|
| idle 空闲 | 在线、无任务 | 初始 / 任务回收 |
| queued 排队 | 已接任务，等待并发槽或上游 | 编排器 / 用户 |
| running 工作中 | 已开始调用，尚无首 token | 调度器 |
| streaming 流式输出 | 首 token 已到，正在产出 | 模型流 |
| done 已完成待验收 | 产物已交，等验收 | 模型 |
| accepted 已验收 | 通过，产物冻结为下游基线 | 主模型 / 人 |
| failed 失败 | 报错、超时、被中断、预算耗尽 | 系统 / 用户 |
| revising 返修中 | 收到返修意见并再次执行 | 主模型 / 人 |
| blocked 等待用户 | 决策卡 / 放行卡 / 权限待确认 | 模型 / 系统 |

**正交标记**（叠加，不占状态）：`dirty` 产物过期、`pinned` 产物冻结、`disabled` 跳过、`config-error` 凭证/配置错误、`offline` 服务不可达、`superseded` 已被新尝试替代。
主模型的「验收中」不是新状态：主模型处于 running，任务行显示「正在验收 T4」。

### 3.2 状态优先级（决定主样式）
配置错误 > 禁用 > 阻塞 > 失败 > 返修 > 流式 > 运行 > 排队 > 过期 > 待验收 > 已验收 > 空闲。
先展示「需要人 / 坏了」，再展示「在动」（n8n `CanvasNodeStatusIcons` 的严格优先级）。可同时挂副徽章（如 running + dirty），主样式按优先级，副徽章画成右上角小角标。

### 3.3 转移表

| 起点 | 事件 | 终点 | 备注 |
|---|---|---|---|
| idle | 收到任务 | queued | 写审计「assigned」 |
| idle | 用户直接对话 / 点运行 | running | 无任务时生成「临时任务」 |
| queued | 获得并发槽 | running | 排队超过 3 分钟显示队列位置 |
| running | 首 token 到达 | streaming | |
| running | 直接返回结构化结果 | done | |
| running | 报错 / 超时 / 中断 | failed | 中断显示「已中断」子标 |
| streaming | 流结束 | done | |
| done | 主模型验收通过 | accepted | 产物冻结 |
| done | 判返修且 attempt < max | revising | 线上出现返修弧线 |
| done | 判返修且 attempt = max | failed | 升级人工 / 决策卡 |
| revising | 重新入队 | queued | attempt+1 |
| failed | 重试 | queued | 保留旧产物版本 |
| failed | 用户跳过 | idle | 任务记「已放弃」，下游 dirty |
| 任意 | 需要用户决定 | blocked | 保存「进入前状态」，回答后恢复 |
| blocked | 用户回答 / 放行 | 恢复前一状态 | 超时按策略 |
| accepted | 上游变更 / 人工改派 | done + dirty | 撤销验收（n8n dirty 反向） |
| 任意 | 用户禁用 | 叠加 disabled | 不执行，连线 30% |
| 任意 | 用户停止 | failed(cancelled) | 部分产物保存 |

### 3.4 每个状态的视觉处理

| 状态 | 边框 | 状态点 / 图标 | 主体变化 | 动效 | 连线联动 |
|---|---|---|---|---|---|
| idle | 1.5px 中性灰 | 灰点 + 「空闲」 | 任务行「待命」 | 无 | 类型色 |
| queued | 1.5px 灰蓝 | 时钟 + 「排队 #2」 | 整体变暗 10% | 无 | 入边变暗 |
| running | 1.5px 蓝 | spinner + 「工作中」 | 任务行显示当前步骤，产物区「思考中…」三点脉冲 | 2s 呼吸光；顶部不定进度条 | 入边流动 |
| streaming | 1.5px 蓝 | 脉冲点 + 「输出中」 | 尾部 3 行实时 token + 渐隐 + `▌` 光标 | 顶部按 token 估算细进度条；卡片上浮 1px | 出边传输中 |
| done | 1.5px 绿 | ✓ + 「待验收」 | 预览 2 行；右上角琥珀小旗 | 完成瞬间 400ms 绿色扫光一次 | 出边成功色 |
| accepted | 1.5px 深绿 | ✓✓ + 「已验收」 | 预览带 ✓ 水印；冻结雪花角标 | 无 | 出边「已冻结」 |
| failed | 1.5px 红 | ! + 「失败」 | 顶部一行错误摘要 + 重试/查看 | 进入时 120ms 抖动一次；错误点常驻 | 出边红 + `×N` |
| revising | 1.5px 琥珀 | 循环箭头 + 「返修 2/3」 | 显示验收理由一行，可展开 | 边框缓慢流动虚线；返修弧线脉动 | 返修边琥珀、2.5px |
| blocked | 1.5px 紫 | 暂停 + 「等你决定」 | 问题一行 | 状态点呼吸；顶栏计数脉动；决策卡入场动画 | 相关线停住 |
| dirty 叠加 | 虚线琥珀 | 三角替换 ✓ | 预览 70% 透明 + tooltip「上游已变更：人工改派 T4」 | 无 | 出边琥珀虚线 |
| disabled | 虚线中性 + 50% | 斜杠 | 去饱和 | 无 | 所有线 30% |
| config-error | 虚线红 | 钥匙 | 「未绑定凭证 / 模型不可用」 | 无 | 出边不可运行 |

### 3.5 节点状态与任务状态的关系
- 节点状态 = 当前最显著任务的投影。一次只跑一个任务；排队多个时任务行显示下一个任务编号。
- 每个任务有独立状态，在计划条与抽屉「任务」tab 可见；节点状态只是它的可视化摘要。
- 同一节点多任务并发 [决策]：MVP 串行（简单、可解释），V2 开放并行池。
- 产物版本 = 每个 attempt 一份；旧版本在「产物」tab 中可查看、对比、固定。

## 4. 画布级交互

### 4.0 顶栏与画布框架
- 顶栏左：团队名（可改）+ 保存状态（保存中 / 已保存 / 离线）。中：运行 HUD。右：「需要你 N」紫色胶囊 / 小地图开关 / 设置 / 分享（V2）。
- 运行 HUD：空闲时显示「运行」按钮；运行中显示「运行中 · 4/6 · ¥0.12 · 3m12s · 队列 2」+ 停止全部。点击「运行」= 入队一份快照（ComfyUI 队列语义），重复点击追加队列。
- 主模型节点在 idle 时任务行显示目标摘要；点击打开抽屉输入/修改目标。有目标时顶栏运行按钮才可用。

### 4.1 空画布引导
- 恢复上次视口；无节点时显示居中合成框「这支 AI 团队要做什么？」+ 主模型选择器 + 3 张模板卡（内容生产线 / 代码流水线 / 调研分析）+「从空白开始」（Langflow 空画布 composer）。
- 未配置任何凭证：仅把 composer 替换为「先接入一个模型」CTA（3 步图示），模板仍可预览与套用（Langflow 做法）。
- 套用模板：生成节点 + 契约边 + 说明便签；未绑定凭证的节点立即显示 config-error，点击进入向导第 2 步。

### 4.2 添加节点（四步内联向导）
- 入口：`N` / 双击空白 / 左侧 `+` / 从端口拖到空白。
- 步骤（就地 popover，不离开画布；Flowise 凭证内联编辑）：
  1. 选服务商：DeepSeek / MiniMax / Claude / OpenAI / 自定义 OpenAI 兼容（填 baseURL）。
  2. 凭证：下拉已有（密钥打码，前端永不见明文，Langflow 遮罩）+「新建」内联表单 + 铅笔编辑。
  3. 模型：按凭证实时拉 `/models` 列表（Flowise `asyncOptions` + `listModels`），可搜索；国内端点失败允许手填 modelId。
  4. 命名 + 默认档位 +「测试连接」（显示延迟 / 错误原文）。完成即建节点，落在点击位置（`screenToFlowPosition`）。
- V2：一个凭证下勾选多个模型批量建节点。

### 4.3 选择、复制、删除
- 单击选中；拖拽框选；Shift+单击加选；Ctrl+A 全选。
- Ctrl+C / Ctrl+V 带 24px 偏移；Ctrl+D 再制；粘贴时保留内部连线。
- Delete 删除；若节点有运行中任务，弹确认「中断并删除？」；`onBeforeDelete` 守卫。删除主模型需二次确认并提示先转移（[决策] 是否允许自动降级给最近使用的节点）。

### 4.4 连接与断开
- 端口拖拽，起点为输出、终点为输入；反向拖拽自动识别。
- 目标节点整体是热区（放大 `connectionRadius`），悬停时兼容端口放大、显示类型名；不兼容端口显示禁止光标。
- 释放空白 → 类型过滤搜索（ComfyUI Link Release）。
- 断开：拖离端口 / 线上 X / 选中 Delete。
- 拖动已有边的目标端到另一个节点 = 改派该契约，弹档位确认，写审计。

### 4.5 分组与便签
- **分组框**：选中 ≥2 节点 Ctrl+G，生成带标题栏的彩色框（7 色预设），可折叠。折叠时显示「研发组 · 4 节点 · 1 运行中 · 1 失败」+ 聚合状态点。组无端口、不可执行（ComfyUI groups 纯视觉，避开其 subgraph 的 bug 史）。缩放 < 0.66 时组描述隐藏（n8n）。双击标题重命名；拖标题移动整组（`parentId` + `extent:'parent'`）。
- **便签**：`S` 或工具栏新建；Markdown 渲染；7 色；可缩放；始终在节点下方（最低 zIndex）；V2 可拖到语境口成为语境。MVP 中便签仅视觉与备注。
- **节点备注**：配置里填写备注，可勾选「显示在节点」渲染为名称下方副标题（n8n Notes）。

### 4.6 导航
- 滚轮 / 双指捏合以指针为中心缩放，范围 0.1–2.5；Space+拖 / 中键拖平移（React Flow `panActivationKeyCode='Space'`）。
- `0` 缩放 100%；`1` 适应全部；`.` 适应选中（n8n / ComfyUI）；`F` 聚焦模式（其余节点 40% 透明，自动 fit 选中，Esc 退出）；`Alt+Shift+M` 小地图开关。
- 小地图：左下 180×120，悬停出现、离开 1.2s 淡出（n8n），节点按状态着色，blocked 节点脉动，可拖视口框。
- 缩放 LOD：< 0.6 节点切紧凑、线隐藏文字；< 0.35 节点退化为「头像 + 状态点」胶囊。
- 双击空白 = 添加搜索；拖入文件到画布建「文档/语境」对象（V2）。

### 4.7 搜索与命令
- `N` 节点搜索（按名称 / 服务商 / 能力标签），回车新建。
- `Ctrl+K` 命令栏（V2）：添加节点、运行全部、运行选中、停止、存版本、导出、跳转 `@节点`、打开对话（n8n 命令栏 / Dify Go to Anything）。
- 计划条任务行、节点名均可双击定位并打开抽屉。

### 4.8 撤销 / 重做
- 自建命令栈（React Flow 的 undo/redo 属于 Pro 付费示例，需自实现）：记录节点 / 边 / 分组 / 便签 / 任务指派 / 档位 / 标签 / 配置变更；800ms 内的连续拖拽合并为一条；栈深 100。
- 不记录：流式 token、运行状态、视口移动、面板开关、自动保存。
- 运行期人工覆写是可撤销的结构命令：撤销只把连线/指派改回并标脏下游，**不会**自动重新执行或退回已花的 token；审计追加「已撤销改派」。
- `Ctrl+Z` / `Ctrl+Shift+Z`（或 `Ctrl+Y`）。

### 4.9 自动保存、快照、导入导出
- 自动保存：任何结构变更后 600ms 防抖写本地 + 服务端；顶栏显示保存状态。
- 运行快照：每次运行冻结一份完整图（节点、契约边、配置、主模型 prompt）作为只读快照，运行记录引用它（Sim View Snapshot）；快照不含凭证。
- 运行中允许编辑结构：当前运行继续用快照，新边下一次运行生效；任务级覆写（改派、档位）立即作用于当前运行。
- 命名版本：`Ctrl+S` 新建命名版本；恢复 = 生成新草稿（Dify Current Draft / Latest），不破坏历史；差异对比忽略布局、只列结构变化（Sim compare）——V2。
- 导入 / 导出 JSON：`{schemaVersion, nodes, edges, groups, notes, viewport, settings}`；凭证只导出 credentialId 占位，导入后未匹配显示 config-error「需绑定」。
- 画布列表：缩略图、最后运行状态、复制、删除、导入（MVP 可放最后）。

### 4.10 运行观察与只读（V2）
- 运行观察：HUD 提供「跟随」开关，视野自动跟随当前任务节点；运行中降低非必要动效。
- 只读分享：隐藏运行 / 删除，全展开分组，便签可读（n8n read-only）。

### 4.11 性能约定（对开发者）
- 流式 token 用 rAF 合批（约 60ms）写入 transient store（zustand 外部 store 或 ref），节点只订阅自己的切片；禁止每 token `setState` 导致全画布重渲染。
- 节点 / 边组件 memo 化；`onlyRenderVisibleElements`；边标签走 `EdgeLabelRenderer`，避免触发 SVG 路径重算。
- 目标规模：常规 30 节点、6 并发运行保持 60fps；200 节点进入 LOD 模式 [决策] 目标规模。

## 5. 点击即对话

### 5.1 打开 / 关闭与视口
- 单击只选中；双击节点、`Enter`、工具条「对话」、点击连线 → 打开右侧抽屉。
- 抽屉宽 380–560px，默认 400，可拖动改宽并记忆；打开时 260ms 缓动把选中对象居中到**剩余画布**（`setCenter` 带右偏移，n8n / AI Elements `<Artifact>`）。
- 关闭恢复打开前精确视口；若用户在打开期间手动平移过，则不强制拉回（「跟随」默认开）。
- `Esc` 关闭；点空白画布关闭（抽屉右上「固定」开启后保持常驻，只随选择切换内容）。
- 切换选择：内容 120ms 淡入替换，视口重新居中；每个对象记忆各自的滚动位置。

### 5.2 抽屉布局

```
┌──────────────────────────────────────────┐
│ [标] Worker 3  deepseek-chat  ● 运行中  ⋯ 固定 ✕ │ 56
│ T4 · 第 2/3 次 · 档位 高（编排）                │ 32 上下文条
├──────────────────────────────────────────┤
│ 对话 | 任务 | 产物 | 日志 | 配置            │ 40 tabs
├──────────────────────────────────────────┤
│ [任务卡] 收到 T4：核对第 3 节…              │
│ [正文流式…]                                 │ 滚动区
│ [产物卡] 已交付：修订稿 v2（4.2k tok）       │
│ [验收卡] 返修：数据口径需单列…               │
├──────────────────────────────────────────┤
│ 附加上游产物 ▾  档位 高 ▾  仅测本节点 ○      │ chips
│ ┌────────────────────────────────────┐   │
│ │ 说点什么…                      ↑    │   │ composer
│ └────────────────────────────────────┘   │
└──────────────────────────────────────────┘
```

- 上下文条常驻：对象名、厂商/模型、任务号、attempt、档位来源（编排 / 人工）。
- **对话**：与该 AI 的持久会话；系统与任务事件以卡片插入（收到任务、交付、验收、返修），让对话即工作日志（Coze 节点聊天 + n8n 节点详情）。
- **任务**：本节点相关任务列表（含历史）；展开看 brief、约束、验收标准、attempt、耗时、成本；底部操作：重跑、编辑后运行、跳过、改派。
- **产物**：按 attempt 列版本，Markdown / JSON / 代码预览，复制 / 下载 / 固定为基线（n8n pin）。
- **日志**：请求/响应摘要、工具调用、原始错误、状态转移时间线；可复制 requestId。
- **配置**：模型、参数、系统提示词、默认档位、凭证（打码 + 铅笔内联编辑）。
- 消息支持 Markdown、代码块、表格；AI 消息带头像与模型徽章，用户消息右对齐；运行中 composer 右侧变「停止」。

### 5.3 线程作用域：节点 / 连线 / 主模型
- **节点线程**：一节点一条长期线程（跨任务保留记忆），任务事件作分隔卡；节点删除时线程归档。这是一个 AI 成员的「专属频道」，不是一次性任务日志。
- **连线线程**：点击线进入连线模式抽屉。
  - 头部：`A → B`、类型、契约摘要（这条线允许传什么）。
  - **消息** tab：按时间列出每次传输（方向、任务号、载荷摘要、token、延迟、重试），点开看载荷快照（只读）。
  - **插入指令**：在下次交接前附加人类指令（V2 落成线中间的「指令注释」小节点）。
  - 输入框默认收件人「下游 B」，可切「上游 A」；发送后进入对应节点线程并打上「来自连线注记」标签。这样「点线也能和具体的 AI 说话」成立（Flowise / Langflow 均无）。
  - **设置** tab：按住/放行开关、标签重命名、断开。
  - 连线线程本质是目标节点线程按 edgeId 过滤的视图 + 传输日志，避免双重存储。
- **主模型线程**：同一抽屉增加「计划」tab（见 6.3）；composer 输入即对主模型下指令，运行中默认排队到本轮结束，并提示「将触发重新规划」[决策]。

### 5.4 上下文 chip 与「仅测本节点」
- composer 上方 chips：
  - 上游产物 chip（默认附着最近快照）：`T3 产物 · 4.2k tok`，可逐个移除，点击预览。
  - 「仅测本节点 / 带上上游」分段开关；隔离模式顶部常驻黄条：「隔离运行：不执行上游，使用上游最后一次快照」（针对 Langflow 用户误读单组件运行的问题）。
  - 本次档位覆盖（低 / 中 / 高 + 自定义 token 预算）。
- `@` 引用（V2）：输入 `@` 弹出分组选择器（上游节点 / 产物 / 便签 / 环境变量），插入为引用 pill（Dify 变量选择器 + Sim inline tag 思路）；内部存结构化引用，导出时才序列化为文本。

### 5.5 流式与节点回显
- 抽屉内：Markdown 增量渲染，代码高亮，末尾光标；停止按钮常驻。
- 节点内：产物预览尾部同步滚动（同一数据源、两个视图）；状态 running → streaming 同步；顶部细进度条按已生成 token 估算。
- 完成：节点折叠为结果摘要 + 产物 chip；抽屉内固化为消息卡。
- 数据链：SSE 分帧 → rAF 批 → transient store → 两处订阅（见 4.11）。

### 5.6 人工覆写交互

| 操作 | 手势 / 入口 | 效果 | 审计记录 |
|---|---|---|---|
| 改派任务 | 主模型任务托盘拖 chip 到目标节点（或拖边端点到新节点、任务 tab「改派…」） | 画布暗化、合法工人光晕、幽灵线跟随、悬停显示预计成本/延迟、松手弹档位气泡；确定后边脉动，原任务标 superseded，下游 dirty | 「人工改派 T4：W2→W4 · 档位高」 |
| 强改档位 | 上下文条 / 任务 tab / 对话 chip | 立即写入任务 effortOverride；节点徽章变「人工 高」；运行中则询问「下一轮生效 / 立即中断重跑」 | 「人工设定 T4 档位 高」 |
| 跳过 | 任务 tab / 右键节点 | 任务关闭为「已放弃」；下游 dirty；主模型收到 skip 事件可重新规划 | 「人工跳过 T4」 |
| 重跑 | 节点 footer / 工具条 / 任务 tab | 用冻结的上游快照重跑（默认），可勾「重新读取上游」；不重复计费上游（n8n Execute step / pin） | 「人工重跑 T4（attempt 3）」 |
| 编辑后运行 | 任务 tab brief 编辑器 →「以此运行」 | 新 attempt，保留旧产物版本；显示相对上一版改动摘要 | 「人工修改 T4 任务书并运行」 |
| 中断 | 节点悬停停止 / 抽屉停止 | failed(cancelled)，保留部分产物 | 「人工中断 T4」 |
| 固定产物 | 产物 tab / `P` | 冻结为下游输入基线，后续运行跳过重算；显示图钉（n8n pin） | 「固定 T4 产物」 |
| 验收裁决 | 任务 tab（人可替代主模型） | 通过 / 返修（填理由）/ 升级；等同主模型 verdict | 「人工验收 T4：返修」 |
| 对话插话 | composer（运行中） | 默认排队为当前步骤后的补充指示；提供「立即中断并采纳」[决策] | 「人工插话 T4」 |

- 所有覆写完成都要有一次性视觉回执（边脉动、节点闪一下、toast），并写入任务日志（Miro / FigJam「看见 AI 在动手」原则）。
- 改派、档位、跳过在 5 秒内可 Ctrl+Z 撤销（见 4.8）。

### 5.7 审计
- 每个任务保存事件流：assigned / started / streamed / artifact / verdict / human-override / skipped / pinned / retried，含操作者（编排 / 人工）、时间、前后值。
- 节点右上角小「历史」图标仅在存在覆写时出现，点开定位到日志对应条目。
- 运行报告导出时包含审计（V2）。

### 5.8 空态与错误态
- 无任务：「还没有任务。直接聊，或让主模型给它派活。」+ 两个按钮（和它聊 / 指派任务）。
- 凭证失效：抽屉顶部红条「凭证已失效」+ 内联修复；节点 config-error。
- 上游失败：「上游 T2 失败，本节点未运行」+「用旧快照运行」。

## 6. 主模型专用层

### 6.1 皇冠与唯一性
- 主模型头部左上角金色皇冠 + 名称后小字「主模型」；节点外圈 1px 金色柔光，运行中缓慢呼吸。
- 设为主模型：工具条 / 右键；已有主模型时弹确认「将主模型从 A 移到 B？」；旧主模型皇冠移除、托盘收起，历史任务保留。
- 主模型不能直接删除，需先转移（[决策] 或改为自动降级给最近使用节点）。
- 主模型永远展开任务托盘与计划条。

### 6.2 任务托盘（Task Tray）
- 作为主模型节点的子节点挂在卡片下方（`parentId` + `extent`，随拖动），宽 320、高 36，一行 chips，溢出折叠为「+N」。
- chip = 任务号 + 状态点 + 指派人缩写（W3）；颜色遵循任务状态；返修任务带 ↻ 与 `2/3`。
- 悬停高亮对应工人；点击选中工人并打开抽屉「任务」tab；拖出 chip 进入改派流程（5.6）；右键菜单：改派 / 跳过 / 查看。
- 运行中显示汇总「3/6 完成 · 1 返修 · 1 待你」。

### 6.3 计划条（Plan Strip）
- 主模型卡片下方（托盘之下）可折叠卡片：标题「计划」+ 运行摘要；每行 = 一个任务：序号、任务一句话、指派人、状态、attempt、验收结果。
- 行悬停出现三个小按钮：对话该工人 / 改派 / 跳过。
- 点击行 = 选中工人 + 打开抽屉；双击任务文字 = 就地编辑任务书（确认后「编辑后运行」）。
- 默认展开前 6 行，超出滚动（最高 260px）；折叠后一行摘要。
- 运行结束保留最近一次计划；多历史切换放 V2（Sim run selector）。

### 6.4 验收判定显示
- 工人节点 done 时右上角裁决徽章：
  - 通过：绿色 ✓ +「主模型通过」，点击看评分条目。
  - 返修：琥珀 ↻ +「返修 2/3 · 数据口径不符」，点击打开抽屉验收段。
  - 升级人工：紫色 ! +「需你裁决」，同时进「需要你」收件箱。
- 验收 rubric：抽屉「任务」里的验收段逐条列标准与通过/未通过理由（Dify checklist 分组思路）；未通过条目可一键「以此返修」。
- 返修边：主模型验收口 → 工人任务口的琥珀弧线，与普通任务边用 ±24px 路径偏移区分；标签「返修 #2」；超预算变红并停住。
- 运行 HUD（顶栏中央）：「运行中 · 4/6 · ¥0.12 · 3m」；点击展开收件箱与停止全部。

### 6.5 推理档位指示
- 档位徽章：`▂▄▆` + 低/中/高；来源前缀「编排 / 人工 / 默认」；人工用类型色描边 + 手形图标。
- 悬停 tooltip：「高 · 预算 16k tokens · 由主模型按任务复杂度指定」。
- 优先级：任务书档位 > 节点默认档位 > 全局默认。节点上的内联控件改的是节点默认档位；任务级覆盖在抽屉或托盘气泡中设置。
- V2 提升为端口：配置开启「档位由连线决定」后，档位变成第 4 个输入口（小方口），内联控件变只读，由调度线动态赋值（ComfyUI widget→port promotion 的核心思想）。

### 6.6 用户决策卡（Choice Card）
- 触发：需要人做选择（范围歧义、预算超限、返修耗尽、敏感操作、放行请求）。
- 形态：画布内就地卡片 360px，锚在发起节点右侧 32px，一条细引线连到节点；不遮挡节点、不弹模态（Dify Human Input / Sim / Wordware 的 inline ask）。
- 内容：标题（谁在问）→ 问题（≤3 行）→ 2–4 个选项按钮（主选项实心）→ 可选自由输入 → 底部「截止 10:00 自动选 A」+「转为对话」。
- 回答后 200ms 收起为计划条中的记录 chip，节点从 blocked 恢复，相关线继续流动。
- 多张卡：画布右下角「待处理 (2)」脉动胶囊；点击按序聚焦（视口飞到卡片）。
- 卡片是画布对象：可拖动、可最小化为节点角标、随节点移动；缩放 < 0.5 时折叠为「等你决定」chip。
- 主模型的选项可映射为计划分支：选择后计划条对应行即时更新。

### 6.7 阻塞收件箱（Needs You）
- 顶栏紫色胶囊「需要你 2」，或抽屉固定入口；列表项：决策卡、放行卡、升级裁决、凭证错误。
- 每条显示：谁、什么问题、等待时长、跳转按钮（选中节点 / 打开卡片）。
- 浏览器标签标题追加 `(2)`；V2 接 Web Push / 邮件通知。

### 6.8 主模型抽屉的特殊性
- tabs：对话 / 计划 / 任务 / 日志 / 配置。
- 计划 tab 是计划条的全屏版：按阶段分组，支持多选行批量改派。
- composer 输入 = 对主模型下指令；运行中默认排队到本轮结束，并显示「将触发重新规划」提示。
- 配置：拆解策略 prompt、最大任务数、默认返修预算、总预算上限、并发数、验收严格度（低/中/高）、自动验收开关。

## 9. 工程落地约定（库可移植）

**React Flow 映射（v12，MIT）**
- 自定义节点、`NodeToolbar`（浮动工具条）、`EdgeLabelRenderer`（中点标签）、`EdgeToolbar`（线上悬停按钮）、`NodeResizer`、`MiniMap`、`Controls`、`Panel`、`Background`。
- `isValidConnection`（拖拽全程校验）、`connectionRadius`（节点整体热区）、`onReconnect` + `reconnectEdge`（改派）、`onBeforeDelete` / `deleteKeyCode`（删除守卫）、`panActivationKeyCode`（Space 平移）、`screenToFlowPosition`（拖放建节点）。
- 分组 = `parentId` + `extent:'parent'`；子节点（托盘 / 计划条）同理。
- 端点放下到空白处开搜索：`onConnectEnd` + 屏幕坐标。
- 自建：命令栈 undo/redo、右键菜单、自动布局（可选 dagre/elkjs）、画布级 DnD 面板、复制粘贴。

**数据分层（关键）**
- `GraphDoc`（保存 / 导出）：`nodes[]`（providerId / credentialId / modelId / role / effort 默认 / config / note / position / size / collapsed）、`edges[]`（契约）、`groups[]`、`notes[]`、`viewport`、`settings`、`schemaVersion`。
- `RuntimeStore`（运行期）：`runs[]`、`tasks[]`、`attempts[]`、status、stream buffers、blockedItems、audit；按 `runId` 隔离，不写回 GraphDoc。
- 运行快照 = 运行开始时的 GraphDoc 深拷贝 + 运行参数（不含凭证明文）。
- 任务模型：`Task { id, runId, title, brief, assigneeNodeId, effort, status, attempt, maxAttempts, dependsOn[], acceptance { criteria[], verdict, reasons[] }, artifactRefs[] }`。

**核心接口（伪代码，便于先写测试）**
- `assignTask(taskId, toNodeId, effort)`：校验类型/环 → 复用或创建契约边 → 写审计 → 标记被替代任务 → 下游标脏。
- `markDirty(nodeId, reason)`：标脏第一层下游；其重跑产生新产物后再逐层传播（n8n 规则）；人工改派则直接把被改派任务及全部下游标脏（口径已变）。
- `setEffort(taskId|nodeId, level, source)`、`skipTask`、`rerunTask(taskId,{usePinnedUpstream})`、`stopTask`、`pinArtifact`。
- `openDrawer({kind:'node'|'edge'|'main', id})`：统一入口，内部维护返回栈。
- `getUpstreamArtifacts(nodeId)`：取最近快照，供隔离运行与「带上上游」。

**其他**
- 视觉 token 集中在 CSS 变量（状态色 / 类型色 / 动效时长 / 圆角），暗色主题仅替换 token。
- 中国网络：模型列表、测试连接、推理请求全部走服务端代理；错误原文回显到节点与向导，不吞错。
- 流式与统计：所有 token 级更新走 rAF 批 + 订阅切片；节点、边、标签三处同源不同视图。
