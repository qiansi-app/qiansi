# 连线产物卡片 · 几何布局规格（布局工程师交付）

## 一、现状

- 卡片中心 = `labelX, labelY`（`getSmoothStepPath` 返回值），配 `translate(-50%,-50%)`，因此卡片必然骑在连线中点上方，这就是用户看到的“压线”。
- 卡片宽度只由 `max-width:220px` 限制，实际尺寸取决于内容，因此布局前无法预计算占位框，避让无从谈起。
- 没有任何碰撞逻辑，所以同一对节点的平行边、密集图、短边三种情况全部重叠。

## 二、约束（不可违背）

1. 只能用 `getSmoothStepPath` 返回的 `d` 字符串和 `labelX/labelY`，**没有切线**，必须自己求。
2. 卡片渲染在 `EdgeLabelRenderer` 里，坐标是**画布坐标**；整层随 `zoom` 缩放。因此所有几何计算必须用画布单位，禁止混入屏幕像素。
3. 边可能只有几十像素，也可能几千像素；同一对节点可能有多条边；全图几十条带产物边。
4. 只用 React + CSS，不引依赖，不做 DOM 测量后布局（会抖动）。
5. 深色主题，色板给定：ok `#4ade80` / warn `#e0a458` / fail `#f87171` / 强调 `#6ea8fe` / 文字 `#c7d2df`。
