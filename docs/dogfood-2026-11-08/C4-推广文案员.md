## 牵丝 DSH 插件

如果你平时用 Claude Code、Codex 等编码 Agent 写代码，也希望在 DSH 会话中直观看到多模型协作背后的 Key 额度与调度情况，牵丝 DSH 插件可以把这些信息接入当前工作流。

安装后，DSH 可通过 MCP 注册 `mcp__qiansi__get_quota` 工具，用于读取牵丝管理的多模型 Key 额度。牵丝目前支持 deepseek、minimax、moonshot、zhipu、qwen、openai 和 relay 等模型家族，并记录各 Key 的每日、每月 token 额度。

### 三条卖点

- **多模型额度一目了然**：在 DSH 会话中直接查询各模型家族的 Key 槽位与日/月额度，不必反复切换界面检查。
- **Key 用尽自动轮换**：当前 Key 额度耗尽时，自动切换到同家族中仍有余额的 Key，并持久化轮换结果。
- **无余额时自动改派**：某个模型家族没有可用额度时，可将对应任务改派给仍有余额的家族中成本最低者，并在任务 rationale 与审计记录中留下依据。
