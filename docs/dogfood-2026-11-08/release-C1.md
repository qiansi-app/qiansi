# 事实清单与未知项

## 断点续跑

**可核验事实**
- 运行失败或中断后，可用 resumeOf 发起续跑。
- 续跑只重新执行没有产出的任务；已完成任务的产出自动作为上游上下文注入。
- 续跑任务带「恢复说明」。
- 续跑期间模型与 Key：优先沿用上一轮模型档案；档案缺失时按画布节点当前模型，因此续跑可以用上新换的模型和 Key。

**触发条件**
- 运行失败或中断后，手动发起 resumeOf。

**界面/入口位置**
- 聊天/API 的 run.start。
- MCP 的 resume_project。
- 「需要人工」面板中失败与中断条目上的「续跑」按钮。

**未知项**
- resumeOf 在聊天/API 中的具体参数或字段未说明。
- 「需要人工」面板的具体入口路径未说明。
- 人工停止的运行能否手动 resumeOf，事实卡未明确；仅明确人工停止不参与自动续跑。
- “没有产出的任务”的判定细节未说明。

## 自动续跑

**可核验事实**
- 运行可带 autoResume 意图。
- 失败或中断后自动排下一次续跑，最多 2 轮。
- 服务重启后，被上次进程中断且带该意图的运行会自动接着跑。
- 人为停止的运行不参与自动续跑。

**触发条件**
- 运行带 autoResume 意图，且发生失败或中断。
- 服务重启恢复：仅限“被上次进程中断且带该意图”的运行。
- 排除：人为停止的运行。

**界面/入口位置**
- 事实卡未列出 autoResume 的界面设置位置；仅说明“运行可带 autoResume 意图”。

**未知项**
- autoResume 的界面/API 配置入口及参数名未说明。
- 自动续跑在界面中的展示、审计位置未说明。
- “最多 2 轮”是否可配置未说明。

## 领导层复盘

**可核验事实**
- 完整评委默认用旗舰模型，优先级：judgeModel > 主控节点模型 > deepseek-v4-pro > relay sonnet；便宜闸门只筛明显通过的。
- 每轮结束由旗舰复盘，输出 verdict / score / suggestions / action，可在运行结果里读到。
- 成果达不到目标时，自动发起一轮多模型讨论，转录落成画布产物「讨论 · 为什么没达标」。

**触发条件**
- 每轮结束自动复盘。
- 多模型讨论触发条件：有任务失败，或平均验收分 < 0.6。

**界面/入口位置**
- 复盘字段在“运行结果”中可读。
- 讨论产物落为画布产物「讨论 · 为什么没达标」。

**未知项**
- 运行结果中复盘字段的具体位置/UI 未说明。
- judgeModel、便宜闸门的配置位置未说明。
- 平均验收分的统计口径未说明。

## 可靠性改进

**可核验事实**
- 运行记录创建即落盘；服务重启把残留的 running 记为 aborted，界面显示「运行已中断」。
- 副作用账本：回写画布与 deliverables 落盘记为效果，启动时自动补投缺失的；deliverables 为每个任务写出 .md + INDEX。
- 优雅停机：/api/admin/stop 与 SIGINT/SIGTERM 先取消在跑运行、flush 额度账本再退出。
- 看门狗：qiansi watchdog [--interval 60] [--once]，按状态退出码自动拉起/报人，人为停止不动。

**触发条件**
- 服务重启：残留 running 标为 aborted；自动补投缺失效果。
- 优雅停机信号或 /api/admin/stop 调用：取消在跑运行、flush 额度账本。
- 看门狗按状态退出码自动拉起/报人；人为停止不处理。

**界面/入口位置**
- 运行记录界面显示「运行已中断」。
- 优雅停机 HTTP 入口：/api/admin/stop。
- 看门狗 CLI：qiansi watchdog [--interval 60] [--once]。
- deliverables 产物：每个任务 .md + INDEX。

**未知项**

- 看门狗“退出码”的具体值、报人方式未说明。
